SurgiAnnotate
==============

SurgiAnnotate 是一个本地优先的手术视频标注工作台。它围绕一个简单的高频流程设计：

  选择标签 → 记录开始（I）→ 记录结束（O）→ 系统自动保存

视频始终是主界面中心；阶段、动作、评分和关键帧放在右侧可切换工作区，因此功能完整但不会把标注员淹没在大量按钮中。


启动
----

安装依赖：

  python -m pip install -r requirements.txt

从项目根目录启动：

  python -m surgui

也可安装为命令行应用：

  python -m pip install .
  surgui

如需从程序直接打开 LabelMe，可额外安装：

  python -m pip install ".[labelme]"

python-vlc 可用时会优先使用 VLC 播放器；没有该依赖时会自动使用 Qt Media 作为后备。建议在 Windows 的正式部署中保留 python-vlc 和项目附带的 VLC 运行时，以获得更广的视频格式兼容性。


主要功能
--------

- 临床级多主题工作台：视频主舞台、阶段/动作/关键帧分轨时间轴、可缩放并可平移的时间视窗，以及互不挤占高度的“标签选择 / 标注记录”工作区；时间轴与记录表双向选择，默认使用高可读性的临床浅色。
- Phase、Task 区间标注，支持重复标签与毫秒级时间码。
- 评分面板，点击分值立即自动保存。
- 预警/关键帧记录，可选择同时保存当前视频画面；也可从“质量 → 批量提取标注关键帧”自动提取所有阶段、动作的中间帧和预警标注的当前帧。
- 项目自动保存、撤销/重做、历史记录编辑/删除和 LabelMe 联动；编辑时可纠正同类型标签，并用当前播放位置快速回填时间。
- 项目级 JSON、通用 CSV、旧版 TXT 兼容导出；旧版 TXT 可导入迁移。
- 数据检查：开始/结束顺序、视频范围、无效评分、重复记录、必填标签、阶段覆盖/空档/重叠/顺序、动作所属阶段以及关联画面完整性。
- 输出目录按视频指纹隔离，避免同名视频覆盖彼此的数据。

顶部进度条显示阶段覆盖率和已审核记录数，不再把“某个标签曾经出现过”
误当作病例完成度；悬停可查看草稿、待审核、错误和提示数量。


快捷键
--------

  Space               播放 / 暂停
  左 / 右方向键        前一帧 / 后一帧
  Shift + 左 / 右      后退 / 前进 1 秒
  Ctrl + 左 / 右       后退 / 前进 5 秒
  I / O               当前标签的开始 / 结束
  F                   保存当前画面
  Ctrl + S            立即保存
  Ctrl + Z            撤销
  Ctrl + Shift + Z    重做
  Ctrl + E            导出
  Enter / Delete      编辑 / 删除记录列表中选中的标注
  F1                  查看快捷键

时间轴聚焦时可用 Ctrl + 滚轮缩放、Shift + 滚轮平移，也可使用时间轴右下方的
前后、加减和倍率按钮。倍率按钮可一键恢复完整时间轴。

在输入框、筛选框或备注编辑器中，播放和标注快捷键会自动让位给文本输入。

系统继续采用单人、单个进行中区间的标注方式：完成当前区间后才能开始下一个
区间。若需要同时记录 Phase 与 Task，请采用先完成 Phase、再完成 Task 的两遍
标注流程。


项目与输出
----------

每个视频都有一个独立病例目录，默认位于 outputs 下：

  outputs/
    video_name_fingerprint/
      project.surgui.json
      project.surgui.previous.json
      images/
      exports/

project.surgui.json 是唯一的无损数据源，包含视频信息、模板、标注、评分和操作审计。程序会使用原子写入保存它，并保留上一个版本作为恢复备份；主文件损坏时会自动从备份恢复并明确提示。

每次手动保存或自动保存后，程序都会创建（若缺失）并刷新当前病例的 exports
文件夹，不必等到最后手动导出。“文件 → 导出数据”仍可用于另选目录。生成内容包括：

- annotations.csv：一行一个标注，适合统计、训练和审阅。
- phase.txt、task.txt 等旧版兼容区间文件。
- assessment_scores.txt 等旧版评分文件。
- surgui_legacy_manifest.json：旧版 TXT 的映射文件，确保含特殊字符或相似名称的分类可以无损重新导入。


模板格式
--------

阶段和动作模板使用 txt。每行一个标签，井号后的两项可作为开始和结束提示；单独一行 -- 用于分组：

  主切口 # 开始提示 # 结束提示
  --
  IOL 植入

阶段和动作页底部提供“导入 / 新增 / 编辑 / 删除”。导入会明确写入当前页对应
的阶段或动作分类；改名会同步已有标注中的显示名称。为避免破坏历史数据，已有
标注记录引用的标签不能直接删除，需要先删除记录或将记录改为其他同类标签。

评分模板也使用 txt：

  手术评分 # 5
  预警帧 # 0

数字表示可选分数为 0 到 N-1。数值 0 表示该行不是评分，而是关键帧/预警标签。


从旧版迁移
------------

先打开相应视频以创建项目，然后选择：

  文件 → 导入旧版 TXT 标注

导入器会保留可识别的区间、关键帧和评分；无法匹配的标签或非法时间会显示在迁移报告中，不会被静默改写。


视觉规范与主题
--------------

所有视觉实现都由项目根目录的 DESIGN.md token 文档驱动。程序在“视图 → 外观主题”中提供三种经过对比度检查的主题：

- 临床浅色：默认主题，适合普通办公光线；以高可读性的冷白与医疗蓝为主。
- 临床深色：适合低照度专注工作；不是简单反色，评分、警告和危险操作仍保留独立语义。
- 手术室低照度：降低界面亮度，以克制的青绿色组织结构，保留清晰的安全提示。

DESIGN.md、DESIGN.clinical-dark.md 和 DESIGN.theatre-dim.md 是主题的权威来源。每个主题均定义颜色、字体、间距、圆角与组件 token；程序会在切换时重新生成 Qt 样式表和原生调色板。
